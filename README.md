# ORBITAL — 验证版（第一阶段）

> 这是任务书的第一阶段验证版，不是完整任务书的交付，也不是生产部署。
> 它可以打开、点击、聚焦、调时间、搜索，并用开普勒模型驱动天体位置。

## 位置模型（诚实说明）

- 坐标：日心黄道 J2000，位置单位 AU；内部时间为 TT（Terrestrial
  Time）近似：`jdFromDate` 输入 UTC，输出 TT 儒略日
  （TT = UTC + ΔT；ΔT 分段近似，2000 年 64.2 s、2026 年约 69.2 s，
  见 `src/astro.js` 注释；2026 年后外推不确定性可达十秒量级）。
  J2000 = 2451545.0 TT。TT 与 TDB 的差别（毫秒级）在此模型中忽略。
- 方法：开普勒方程求解（椭圆轨道），不是固定圆形轨道。求解器只接受
  0 ≤ e < 1，非法输入抛错；高偏心率在 M ≈ ±π 附近牛顿法发散时回退
  到二分法（旧版在此处曾静默返回错误值，见 `src/astro.js` 注释）。
- 视位置改正（本轮新增）：光行时迭代 1 次
  （`positionWithLightTime`，地心视位置需传入地球位置；不传时退化
  为日心距离近似并标注）与岁差 IAU 2000 近似（J2000 → 当日平黄道，
  2026 年约 +0.363°，2100 年约 +1.397°，J2000 处恒等）。
  未实现：章动、光行差——文档与代码中明确标注未实现，不得声称已实现。
- 行星 + 冥王星：JPL《Keplerian Elements for Approximate Positions of the
  Major Planets》的 J2000 轨道根数 + 世纪变化率。适用期 1800–2050
  （TT，儒略日 2378496.5–2470172.5）；`astro.isOutOfRange` 供 UI 显示
  警告，超出后位置仍可算但标注“超出适用期，精度无保证”。
- 矮行星 / 小行星 / 彗星：SBDB 正式轨道解（见下），但位置仍按固定
  椭圆从 SBDB 历元外推，无摄动与非引力改正；SBDB 未给出适用期，
  故适用期标“未知”，不得当作精密星历使用。彗星的轨道解历元
  （`epochJd`）与近日点时刻（`perihelionJd`）分开记录，不再混用。
- 卫星：简化开普勒模型（距离、周期、偏心率、倾角为已知量，黄道系
  示意，非母天体赤道系；无交点退行与近地点进动改正），不是完整月球
  / 行星卫星理论。相位规则：只有月球保留历元锚定的相位（218.32°，
  历元 J2000）；其余 20 颗卫星旧整数相位为未核实占位值，现已置为
  `phaseDeg: null` 并标示意，`moonPosition` 对其抛错（调用方须跳过
  或标注示意，不得绘制占位相位）。
- 地球条目位置为地月系质心（EMB），非地心：地心差约 4670 km。
  事件计算使用 EMB 位置（见 `src/events.js` 注释），不适用于日食 /
  掩食几何。
- 面板位置为 J2000 几何位置，非当日视位置：场景坐标为日心黄道 J2000 几何位置，未换算为当日视位置。（事件计算另用光行时改正，见 `src/events.js` 注释；岁差改正不改变事件角距，见该文件注释。）
- 数据日期语义（Phase 2.5）：JPL 支与卫星条目分 `sourceDate`（数据源日期，未查到可核实值时为 null，面板示“未知”）与 `fileUpdated`（本仓库整理日期 2026-10-31）两栏；SBDB 支保持现状（`updated` 即轨道解算日期 `solnDate`）。JPL 表版本号未收录，不得编造引用。
- Horizons API 已于 2026-10-31 实测可达：
  `https://ssd.jpl.nasa.gov/api/horizons.api`，无密钥；实测火星矢量
  星历（2026-01-01 / 02，太阳中心，DE441，TDB）返回正常。
  **本静态版未实时接入 Horizons**，也没有服务端代理；实时星历接入
  属于第二阶段（托管部署）工作。**未做 Kepler 与 Horizons 的数值
  对比**，精度结论不得引用为实测对比值。
- SBDB 已于 2026-10-31 实测接入成功（此前 404 是错误的主机/路径）：

## 视觉说明

- 表面纹理全部为程序化 Canvas 生成（颜色带 / 噪声），不是 NASA 实测影像。
- 土星环含卡西尼缝示意间隙；木星 / 天王星 / 海王星环为示意薄环，
  未标注为真实测量数据。
- 比例模式：
  - 科学比例：真实 AU 距离与真实半径比，天体看起来很小是正确的。
  - 视觉探索：距离与半径均做艺术放大，与物理数据分离，UI 常驻标识。

## 架构

```
index.html          页面骨架与布局（深色电影主题）
src/astro.js        儒略日、开普勒求解、轨道根数 -> 日心黄道坐标
src/data.js         天体目录、物理参数、数据来源（null = 未知）
src/render.js       Three.js 场景、程序化纹理、环、大气、星空、LOD、相机平滑聚焦
src/interaction.js  点击选中、聚焦链、搜索定位
src/time.js         模拟时钟（播放/暂停/加速/减速/倒退/指定日期/回到现在）
src/ui.js           左侧导航、右侧信息面板（中英双名）、设置
src/events.js       合相 / 冲日检测（地心三维角距 + 极值 bracketing，阈值 5°，内行星不报冲日；EMB 基准，见文件注释）
src/main.js         主循环：时钟 -> 位置 -> 渲染 + UI
test_kepler.mjs     Node 测试：开普勒求解器与目录位置有限性
```

## 本地运行（无构建步骤）

```bash

python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

也可以把整个文件夹静态托管，或发布到 GitHub Pages（本阶段不自动推送，
推送需用户连接 GitHub 后另行进行）。

## 测试

```bash
node test_kepler.mjs
node --check src/astro.js src/data.js src/time.js src/events.js src/render.js src/interaction.js src/ui.js src/main.js
```

测试内容：TT 儒略日已知值（2000 年 64.2 s、2026 年 69.2 s）、
开普勒求解残差（含高偏心率 ±π 区域二分法回退）、非法输入抛错、
SimClock 非法日期 guard、JPL 适用期标志、光行时 τ = 距离/c、
岁差量级与 J2000 恒等、地球一个恒星年后回到起点附近（容差
0.02 AU，含世纪变化率）、所有目录天体在 1900 / 2026 / 2100 年的
位置有限（仅月球卫星可算；其余卫星相位为 null 时断言抛错）、
哈雷与 67P 在各自近日点时刻的日心距 ≈ SBDB q 值、SBDB 九体
orbitSolution 字段齐全、事件已知日期对照（见上）。
