# ORBITAL — 验证版（第一阶段）

> 这是任务书的第一阶段验证版，不是完整任务书的交付，也不是生产部署。
> 它可以打开、点击、聚焦、调时间、搜索，并用开普勒模型驱动天体位置。

## 位置模型（诚实说明）

- 坐标：日心黄道 J2000，位置单位 AU；时间由 UTC 换算为儒略日。
- 方法：开普勒方程求解（椭圆轨道），不是固定圆形轨道。
- 行星 + 冥王星：JPL《Keplerian Elements for Approximate Positions of the
  Major Planets》的 J2000 轨道根数 + 世纪变化率。适用期约 1800–2050，
  该区间外误差增大，超出后请勿当作精密星历使用。
- 矮行星 / 小行星 / 彗星：近似密切轨道根数，相位仅供参考，UI 中明确标注。
  哈雷与 67P 的相位由近日点时刻推算。
- 卫星：简化开普勒模型（距离、周期、偏心率、倾角为已知量，相位为 J2000
  参考相位），不是完整月球 / 行星卫星理论。
- Horizons API 已于 2026-10-30 实测可达：
  `https://ssd.jpl.nasa.gov/api/horizons.api`，地球向量星历返回星历源 DE441，
  无需密钥。**本静态版未实时接入 Horizons**，也没有服务端代理；
  实时星历接入属于第二阶段（托管部署）工作。
- SBDB 端点在检查中返回 404，尚未按官方文档核对成功，因此小天体
  轨道解、观测弧长、不确定性在本版中显示为“未知”，不编造。

## 视觉说明

- 表面纹理全部为程序化 Canvas 生成（颜色带 / 噪声），不是 NASA 实测影像。
- 土星环含卡西尼缝示意间隙；木星 / 天王星 / 海王星环为示意薄环，
  未标注为真实测量数据。
- 比例模式：
  - 科学比例：真实 AU 距离与真实半径比，天体看起来很小是正确的。
  - 视觉探索：距离与半径均做艺术放大，与物理数据分离，UI 常驻标识。

## 架构

```
index.html          页面骨架与布局（深色电影主题）
src/astro.js        儒略日、开普勒求解、轨道根数 -> 日心黄道坐标
src/data.js         天体目录、物理参数、数据来源（null = 未知）
src/render.js       Three.js 场景、程序化纹理、环、大气、星空、LOD、相机平滑聚焦
src/interaction.js  点击选中、聚焦链、搜索定位
src/time.js         模拟时钟（播放/暂停/加速/减速/倒退/指定日期/回到现在）
src/ui.js           左侧导航、右侧信息面板（中英双名）、设置
src/events.js       合相 / 冲日检测（阈值 3°，仅由开普勒模型计算）
src/main.js         主循环：时钟 -> 位置 -> 渲染 + UI
test_kepler.mjs     Node 测试：开普勒求解器与目录位置有限性
```

## 本地运行（无构建步骤）

```bash
cd orbital
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

也可以把整个文件夹静态托管，或发布到 GitHub Pages（本阶段不自动推送，
推送需用户连接 GitHub 后另行进行）。

- 太阳、8 行星、冥王星、谷神星、阋神星、鸟神星、妊神星、主要卫星、
  灶神星 / 智神星 / 爱神星、哈雷 / 67P 彗星目录、搜索、分类

- 合相 / 冲日检测（开普勒模型，阈值 3°）

## 测试

```bash
node test_kepler.mjs
node --check src/astro.js src/data.js src/time.js src/events.js src/render.js src/interaction.js src/ui.js src/main.js
```

测试内容：儒略日已知值、开普勒求解残差、地球一个恒星年后回到
起点附近（容差 0.02 AU，含世纪变化率）、所有目录天体在
1900 / 2026 / 2100 年的位置有限、哈雷近日点距离约 0.586 AU。
